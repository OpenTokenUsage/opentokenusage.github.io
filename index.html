Make the taskbar yours

  • Tray icon

  • Taskbar strip

    Logos with session and weekly numbers inside the taskbar, in your fonts, sizes, colors and order.

    Up to 6

  • The panel

    Open it from the tray, the strip or a global shortcut. Pin it above other windows, or turn on Remember position and it opens wherever you drag it.

Your usage stays on your PC

  • No telemetry

    The app sends no analytics. Usage goes from each provider to your PC and nowhere else. Besides the providers you turn on, it contacts only their status pages, and GitHub for updates.

  • Local HTTP API

    On by default: other apps on your PC can read your usage. Loopback only; browsers are refused.

    127.0.0.1:6736

  • Proxy

    Route provider requests through a SOCKS5 or HTTP proxy, set in a config file.

  • Updates

    Checks for new releases every 6 hours and downloads them. Installs when you click Restart to update.

  • Open source

    MIT licensed. Every line is on GitHub.

Questions

  • How do I see my Claude Code usage limits on Windows?

    Install OpenTokenUsage and stay signed in to Claude Code. The app uses Claude Code's existing login, so there's no API key to set up, and shows your 5-hour session limit and weekly limit next to the clock, with reset times, pace and extra usage.

  • How do I check my Codex usage limits?

    Sign in to Codex as usual. OpenTokenUsage reads that login and shows the 5-hour and weekly limits, the code review limit and credits, and can warn you before you run out.

  • Is there a CodexBar for Windows?

    CodexBar and OpenUsage live in the macOS menu bar. OpenTokenUsage does the same job in the Windows 11 notification area: it's built on OpenUsage, inspired by CodexBar, and made for Windows.

  • Which AI coding tools does it track?

    Claude, Codex, GitHub Copilot, Cursor, Antigravity, JetBrains AI Assistant, Devin, Kiro, OpenCode Go, Z.ai, Kimi Code, Factory (Droid), MiniMax, Grok, Amp and Synthetic. Each one is a plugin, and new ones arrive with app updates.

  • Can it warn me before I hit a limit?

    Yes. It notifies you at the usage levels you pick (80% and 95% by default), when you're on pace to run out before the reset, and when a limit resets, with a sound of your choice.

  • Does it send my usage or logins anywhere?

    No. There's no account and no telemetry. Your logins stay on your PC, and the app talks only to the providers you turn on, their status pages, and GitHub for updates.

  • Is it free?

    Yes. It's free and open source under the MIT license. Install it with winget or the installer from GitHub Releases. If it saves you time, you can buy me a coffee.
